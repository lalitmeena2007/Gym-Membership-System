# Gym Membership Management System

A web-based **Gym Membership Management System** developed using **Java, JSP, Servlets, CSS, and MySQL**. The system helps gym administrators manage member records and simplify day-to-day membership operations through a structured digital platform.

## Features

- Add new gym members
- View member details
- Update member information
- Delete member records
- Manage membership-related information
- Store and retrieve data using MySQL
- User-friendly web interface
- Java Servlet-based backend
- Responsive styling using CSS

## Technologies Used

- **Java**
- **JSP**
- **Servlets**
- **JDBC**
- **MySQL**

## How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/lalitmeena2007/Gym-Membership-System.git
```

### 2. Open the Project

Open the project in **Eclipse IDE** and configure it as a Dynamic Web Project.

### 3. Configure MySQL

- Install MySQL.
- Create a database for the project.
- Import the SQL file provided in the repository.
- Update the database connection details in the Java database connection file.

### 4. Configure Apache Tomcat

- Install **Apache Tomcat**.
- Add Tomcat to Eclipse.
- Deploy the project on the Tomcat server.

### 5. Run the Application

Start the Tomcat server and open the application in your browser.

## Database

The project uses **MySQL** for storing and managing gym membership information.

The database contains the required tables for managing member records and related information.

## Project Purpose

The main purpose of this project is to replace manual gym record management with a structured digital solution. It provides an easier way for administrators to maintain member information and perform basic membership management operations.
